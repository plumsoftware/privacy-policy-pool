## 2. Какие данные собираются

### 2.1 Данные, которые хранятся на вашем устройстве

Следующие данные хранятся **исключительно на вашем устройстве** и не передаются на наши серверы:

- Настройки Приложения (например, выбранная тема оформления)
- Данные о состоянии воспроизведения, необходимые для работы плеера, уведомления и виджета

Мы не требуем регистрации и не собираем ваше имя, адрес электронной почты, номер телефона и другие персональные данные напрямую.

### 2.2 Данные, собираемые автоматически

Приложение использует сторонний рекламный сервис, который может автоматически собирать следующие данные:

| Данные | Цель | Сервис |
|--------|------|--------|
| Рекламный идентификатор устройства (GAID / OAID) | Показ рекламы | Яндекс РСЯ |
| IP-адрес | Определение региона для рекламы | Яндекс РСЯ |
| Тип устройства, модель, версия ОС | Корректный показ и совместимость рекламы | Яндекс РСЯ |
| Данные о показах и кликах по рекламным объявлениям | Учёт показов, монетизация | Яндекс РСЯ |

### 2.3 Данные при воспроизведении радиопотоков

Для воспроизведения радиостанций Приложение подключается к потоковым серверам радиостанций и их операторов. При таком подключении серверу, как и при любом обращении к интернет-ресурсу, автоматически передаются технические данные, в том числе ваш IP-адрес и сведения об устройстве. Эти данные обрабатываются владельцами соответствующих потоков в соответствии с их собственными политиками. Мы не контролируем такую обработку.

## 3. Сторонние сервисы

### 3.1 Рекламная сеть Яндекса (РСЯ) (ООО «Яндекс»)

Используется для показа рекламных баннеров в Приложении. Яндекс РСЯ может собирать следующие данные:

- Рекламный идентификатор устройства
- IP-адрес для определения региона
- Технические характеристики устройства
- Данные о просмотренных и нажатых рекламных объявлениях

Эти данные используются для подбора релевантных рекламных объявлений и учёта показов.

- [Политика конфиденциальности Яндекса](https://yandex.ru/legal/confidential)
- [Условия РСЯ](https://yandex.ru/legal/partner_ch_adv)

Вы можете ограничить персонализированную рекламу в настройках устройства:

- **Android:** Настройки → Конфиденциальность → Реклама → Отказ от персонализированной рекламы (точное название пункта зависит от производителя и версии ОС)

## 4. Как используются данные

Собранные данные используются исключительно в следующих целях:

- **Обеспечение работы Приложения** — воспроизведение радиостанций, работа уведомления плеера и виджета, сохранение настроек
- **Показ рекламы** — монетизация Приложения через рекламные баннеры Яндекса

---

## 5. Хранение данных

### 5.1 Локальное хранилище

Настройки Приложения хранятся **только на вашем устройстве**. Мы не имеем доступа к этим данным. При удалении Приложения все локальные данные удаляются вместе с ним.

### 5.2 Данные сторонних сервисов

Данные, собираемые Яндекс РСЯ, а также владельцами радиопотоков, хранятся на серверах соответствующих компаний в соответствии с их политиками конфиденциальности.

---

## 6. Передача данных третьим лицам

Мы **не продаём, не передаём и не раскрываем** ваши персональные данные третьим лицам, за исключением:

- Сторонних сервисов, перечисленных в разделе 3 настоящей Политики, в объёме, необходимом для их работы
- Случаев, предусмотренных действующим законодательством Российской Федерации

## 7. Разрешения Приложения

Для корректной работы Приложение может запрашивать следующие разрешения:

| Разрешение | Зачем нужно |
|------------|-------------|
| Доступ в интернет | Воспроизведение радиопотоков и загрузка рекламы |
| Состояние сети | Определение доступности сети для воспроизведения |
| Уведомления | Отображение управления плеером в шторке уведомлений |
| Служба переднего плана (воспроизведение мультимедиа) | Воспроизведение радио при свёрнутом Приложении или выключенном экране |

Мы не запрашиваем доступ к вашим контактам, камере, микрофону, геолокации и файлам.

## 8. Безопасность данных

Мы принимаем разумные меры для защиты данных:

- Настройки хранятся локально на вашем устройстве
- Взаимодействие со сторонними сервисами осуществляется по защищённым протоколам (HTTPS/TLS), где это поддерживается соответствующим сервисом
- Мы не собираем данные, которые позволяют напрямую идентифицировать вас

Тем не менее ни один способ передачи данных через интернет не является абсолютно защищённым. Часть радиопотоков может вещаться по незащищённому протоколу HTTP — это определяется владельцами радиостанций.
